# Contributing

First of all, thanks for contributing! This document provides some basic guidelines for contributing to this repository.

## Submitting Issues

- For feature requests, open a [GitHub issue](../../issues/new) describing the use case and proposed behavior.
- For bug reports, include reproduction steps, expected vs. actual behavior, and your environment (OS, client version, plugin version).

## Pull Requests

1. Fork the repository and create your branch from `main`.
2. Make focused changes with clear commit messages.
3. Ensure existing tests pass and add coverage for new behavior where applicable.
4. Open a pull request describing what changed and why.
